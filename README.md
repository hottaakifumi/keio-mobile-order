慶應義塾大学の食堂におけるモバイルオーダーシステム(模擬的)

・背景

食堂を使ったことがあり、食券を買うのだが、そこでの待ち時間が非常に長い。そこで、モバイルオーダーシステムを導入することで、
券売機に並ばなくても食堂で昼食などをとれるようにしようと考えた。将来、本格的に導入出来たら良いなとも考えている。

・概要

大学食堂での利用を想定したモバイルオーダーシステムである。ユーザーは事前にメニューを選択し、支払い方法を選ぶことで注文が出来る。
注文が完了すると注文番号が自動で発行され、当日は注文完了画面を提示することで商品を受け取ることを想定している。
なお、こちらは模擬システムであり、クレジットカードやQRコードを決済方法として選んでも、実際に決済処理は行わない。

〇主な機能

・メニュー選択機能
ユーザーが食堂のメニューを選択できる

・注文機能
選択したメニューを注文できる

・支払い方法選択
現金・クレジットカード・QRコードといった支払い方法を選択できる

・注文番号の発行
注文完了時に注文番号を自動で生成して表示

・受け取り案内表示
注文完了後に、受け取り場所の案内を表示

・使用技術

〇フロントエンド

html,css,javascript

〇サーバーサイド

Node.js

・技術選定理由

〇html,css,javascript

Webブラウザ上で動作するアプリケーションを作成するために使用した。
特にjavascriptを使用して、注文内容の取得や画面表示の更新などの処理を実装している。

〇Node.js

クライアントから送信された注文情報を受け取り、注文番号を生成するために使用した。

・開発について

開発の際には、chatgptを壁打ちとして使用し、自分の望む仕様へ修正した。
